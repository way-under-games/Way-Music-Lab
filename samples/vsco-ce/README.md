# VSCO CE compact recorded bank

95 derivative mono 24 kHz, 16-bit WAVs from VSCO 2 Community Edition, **CC0 1.0**. Original recordings: Versilian Studios / Sam Gossner and Ivy Audio / Simon Dalzell; sample cutting: Elan Hickler / Soundemote. [Publisher](https://versilian-studios.com/vsco-community/).

See the root [attributions](../../ATTRIBUTIONS.md) and [license analysis](../../LICENSE-ANALYSIS.md) for source revisions, modifications, credits and distribution scope. `manifest.json` records exact source URLs and source/derivative hashes. The nine `.sfz` files and `UPSTREAM-*` files are retained source maps and notices. The browser uses our JSON manifest, not a general SFZ interpreter.

Rebuild with `node scripts/prepare-samples.mjs` from the repository root. Network access is only required for rebuilding. The importer caches original WAVs under ignored `.cache/vsco`; that cache is not published. Our converter, selection metadata, manufactured loops and mix choices are documented in the attribution file. The recordings keep their CC0 designation; original converter/player code is MIT.
